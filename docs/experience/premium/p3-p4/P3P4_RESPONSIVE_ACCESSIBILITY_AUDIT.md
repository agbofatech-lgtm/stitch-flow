# Responsive + Accessibility

Desktop: rail + inspector.

Tablet: collapsible rail, inspector as sheet.

Mobile: six-room tab bar (canonical workspaces, not every operations surface). Operations via header chips / command palette.

A11y: skip link, `aria-current`, landmarks, 40px min nav targets, focus-visible, Escape on dialogs, command palette arrows + Enter, reduced motion.
