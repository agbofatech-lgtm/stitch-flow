# P3/P4 Experience Architecture

FACT vs PROPOSAL

Governing equation: Beauty × Function = Experience. Premium = Identity × Clarity × Craft × Motion × Responsiveness × Trust.

```
PREMIUM EXPERIENCE
  └─ PRODUCT WORKSPACE (AtelierShell)
       ├─ Atelier navigation (canonical rooms)
       ├─ WorkspaceHeader (where / what / action / state)
       ├─ WorkspaceCanvas
       ├─ Inspector (supporting, not authority)
       └─ StatusBar (connectivity from T2)
  └─ DOMAIN SERVICES (unchanged)
  └─ TRUSTED TAILORING CORE (unchanged)
```

Planes

- Digital Atelier: craft, clients, measurements, design host, production, operations.
- Control Center: operator command room. Same tokens, denser Inter display, dark theme via `data-theme="dark"`.

UI presents domain authority. UI is never domain authority.

P5/P6 still owns full module interiors. P3/P4 establishes shell grammar.
