# SER transformation priority map

Derived from debt, not from a desire to “add more glass”.

```
FOUNDATION (F1)     identity: digital atelier, not SaaS dashboard
     ↓
VISUAL LANGUAGE (F2)  make product rooms use tokens; retire TailorPro manifest;
                      do not restyle via the preview island alone
     ↓
MOTION LANGUAGE (F3)  arrival + room + meaningful moments — not more splash
     ↓
SHELL (F4)            StudioShell is already authority — refine, don't replace with Layout
     ↓
CORE WORKROOMS (F5)   Home, Measurements, then Clients/Orders as atelier objects
     ↓
STUDIO FRAME          chrome around protected canvas only
     ↓
OPERATIONS            Production/Invoices only after data contract (not unauthenticated CRUD)
     ↓
DATA EXPERIENCE (F6)  adapters; AppContext remains until a later SAC-level handoff
     ↓
RESPONSIVE (F7)       lab 320–1920; inspector/mobile nav
     ↓
LAB (F8)              a11y + motion + perf
     ↓
CINEMATIC CERT (F9)   screenshot lab required — F0 did not have one
```

## Quick wins (high notice, low architecture)

- Manifest name/colors → StitchFlow atelier (F2)
- Stop shipping Experience Foundation as the “proof” of product redesign
- Status/error copy that does not tell tailors to hit `/customers` on an unmounted API
- Shared Dialog for Orders/Materials (F5 interaction)

## Structural

- One visual language inside Workrooms, not just around them
- Object continuity (client as a thread)
- Cinematic moments for freeze / finalize / production — without formula changes

## Protected

- DesignStudio internals, patternEngine, productionAssistant, types vocabulary, stage engine

## Deferred

- Screen migration to `/shop`
- T2 remote sync auto-start
- Invoices/payments/platform as atelier
- 3D, Phase 20, PSP
- Remounting unauthenticated CRUD as a “UX fix”
