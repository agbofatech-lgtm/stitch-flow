# Thematic coherence audit

Question: one world, or several applications sharing a repository?

**Evidence: several languages sharing one shell.**

| Room | Language |
|---|---|
| Splash + Atelier Home + shell | Warm-paper atelier (closest to intended identity) |
| Measurements | Technical workroom / domain table |
| Design Studio | Creative canvas tool (legacy monolith) inside a thin frame |
| Production / Clients / Invoices | HTTP admin + error states (when backend CRUD unmounted) |
| Orders / Materials | Form/table operations app |
| Reports | Generic KPI dashboard cards |
| Settings | Workspace forms, still mixed |
| Control Center | Dark operator/control-plane JSON |
| Experience preview | Token museum (not the product) |
| PWA manifest | “TailorPro” productivity PWA |

StitchFlow is **not yet** a single premium digital atelier. It is a **tokenized atelier frame** around **dashboard, HTTP admin, canvas, and control-plane** interiors.

That is why it can feel like “SaaS with tailoring labels” even after PEX: the frame changed more than the rooms.
