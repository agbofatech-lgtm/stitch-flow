# Accessibility constitution

Cinematic identity must coexist with access. Not a WCAG certificate.

| Area | Principle |
|---|---|
| Keyboard | All primary actions reachable; Cmd/K remains; skip link stays |
| Focus | Visible token ring; trap **only** in shared Dialog; restore on close |
| Semantics | One h1 per room (title); kicker is not a heading soup |
| Screen readers | Status/error announced (`role=alert` for failures; live region for milestone success) |
| Contrast | Ink on paper; no glass that fails body text |
| Reduced motion | Mandatory collapse of MICRO–MILESTONE |
| Touch | 44px minimum for primary mobile targets |
| Errors | Text, not color alone |

**Prohibits:** custom modals without Escape/trap; motion that cannot be turned off; contrast-breaking atmosphere.
