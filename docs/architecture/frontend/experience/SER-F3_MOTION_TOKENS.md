# SER-F3 motion tokens

| Token | Why |
|---|---|
| instant 80ms | reduced-motion / focus-safe |
| micro 100ms | press |
| fast 140ms | dialog/context |
| base 220ms | workspace |
| slow 280ms | longer spatial |
| milestone 320ms | real commitment only |
| ease standard / enter / exit / emphasize | enter vs leave |

CSS: `--sf-duration-micro`, `--sf-duration-milestone`, `--sf-ease-enter`.
