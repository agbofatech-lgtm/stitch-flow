# User journey model

Not implemented. Intended experience only.

```
ENTER
  → ORIENT (Floor)
  → SELECT CLIENT
  → CAPTURE MEASUREMENTS
  → CREATE DESIGN
  → VERIFY READINESS
  → FINALIZE / TRUSTED ARTIFACT   (commitment)
  → PREPARE PRODUCTION
  → TRACK PRODUCTION
  → COMPLETE ORDER
  → LEDGER (when the work needs money/paper, not as the home)
```

## Emotional beats

| Beat | Where it should be felt | Must not feel like |
|---|---|---|
| Discovery | Floor, client search | KPI dashboard |
| Concentration | Measurement table | Spreadsheet dump |
| Creativity | Design table / hosted studio | Buried settings form |
| Verification | Readiness before finalize | Silent save |
| Commitment | Trusted finalization (SAC-1) | Another modal among many |
| Production confidence | Floor of stages, valid transitions only | HTTP error wall |
| Completion | Delivery / closed order | Vanishing row |

## Continuity rule

The same **client** and **order** remain named in chrome while the tailor moves rooms. F0’s WorkflowPanel badges are **not** this journey; they are a list.

## Out of journey (still in product)

- Control Center: operator, not craft path
- Settings: configuration
- Invoices/payments: ledger stations; not the spine
- SAC-5 sync: infrastructure; surface honesty, not a tourist feature
