## One-paragraph runtime truth

The product a tailor uses is a React SPA with no URL router. Studio, orders, materials, and reports persist in `localStorage` via AppContext. Pattern geometry is regenerated by a protected pure engine in the web app. The process `npm run dev:backend` starts is `apps/backend/src/server.ts` → `createApp()`, which always serves health plus P19 `/auth`, `/platform`, `/control`, and **does not** mount shop CRUD unless `MOUNT_UNAUTHENTICATED_BUSINESS_ROUTES=true`. PostgreSQL is declared and **not** the live platform store. A governed deterministic core exists, is tested, and is **not** what Design Studio calls.

## What StitchFlow is not (FACT)

- Not an authenticated multi-tenant shop API in the default boot
- Not a live billing product
- Not an LLM-authoritative tailoring engine
- Not a 3D fitting system
- Not offline-first in the ADR-002 target sense (accidental local-first for some modules; network-hard for others)
- Not a single customer population
- Not production-certified (P18/P19/PEX are conditional; several owner acceptances pending)
