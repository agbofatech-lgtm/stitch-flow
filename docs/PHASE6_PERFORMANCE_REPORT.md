# STITCHFLOW PHASE 6 PERFORMANCE REPORT

Date: 2026-08-27 · All numbers below are **measured**, none estimated. Machine: sandbox CI container (Node 22.22.3). Raw artifact: `apps/backend/tests/perf-results.json` (regenerated by `npx jest tests/performance-baseline.test.ts`).

## Methodology

- **Backend**: in-process supertest against the real Express app + embedded PostgreSQL 18.4, single workspace seeded with a production-like dataset (300 customers, 200 orders, 200 sync_changes rows). Every measured request is status-checked; a 4xx/5xx during measurement fails the run (a latency number for an error response is not a measurement).
- **Percentiles**: nearest-rank over the stated sample size (n).
- **Query plans**: `EXPLAIN (ANALYZE, FORMAT JSON)` executed against the seeded dataset.
- **Frontend**: byte sizes of `apps/web/dist` after `npm run build` (production build, PWA precache generated).
- Not measured here (no production environment in this session): real-network latency, cold-start times on target hosting, P95 under concurrent load. Classification: **VERIFICATION REQUIRED (production)**.
