# P16 Input Authority Model

| Input | Source | Live UI |
|---|---|---|
| Measurements | `engineInputFromVersion(MeasurementVersion)` | refused |
| Garment type | frozen specification | refused |
| Pattern kind | composition `patternProjection` if present | not invented |
| Configuration | T10 registry identity | not applied as filled defaults |

Unfrozen records throw STOP. Composition must reference the provided specification id.
